# Databento — CME FX futures

Production feed for **6E, 6J, 6B, 6M** etc. Native integration with NautilusTrader (DBN format).

```bash
pip install databento
set DATABENTO_API_KEY=...
```

Export target: `cache/exports/databento/`

Replaces FRED daily proxy in `cache/exports/pysystemtrade/` when live research begins.

Docs: [databento-python](https://github.com/databento/databento-python)

# tar1090 — fonti dati

- **Portale dati:** [ADS-B readsb · adsb.lol aggregate](https://adsb.lol/)

- **Demo:** https://adsb.lol/

UI web per ADS-B locale o rete aggregata. Nessuna API key per decoder proprio.

## Input (decoder locale) (3)

1. readsb — ADS-B decoder (preferred)
2. dump1090-fa — FlightAware fork
3. dump1090-mutability — limited aircraft details

## Feed aggregati pubblici (siti che usano tar1090+readsb) (4)

1. adsb.lol
2. globe.adsbexchange.com
3. globe.airplanes.live
4. globe.adsb.fi

## Dati visualizzati (3)

1. ICAO hex, callsign, altitude, speed, heading
2. Track history (configurable interval)
3. MLAT / TIS-B quando disponibile

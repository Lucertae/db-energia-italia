# Rotki — fonti dati

- **Portale dati:** [Exchange + on-chain sync](https://docs.rotki.com/)

- **Demo:** https://rotki.com/

Desktop self-hosted. Dati salvati localmente encrypted. Molti exchange richiedono API key utente.

## Provider integrati (da docs) (7)

1. Ethereum + L2 — on-chain balances via RPC / Etherscan-like APIs
2. Bitcoin — UTXO tracking
3. Exchange APIs — Binance, Kraken, Coinbase, etc. (user keys)
4. DeFi protocols — Aave, Uniswap, Compound (on-chain decode)
5. Traditional — manual entry / CSV import
6. CoinGecko — price oracles (free tier)
7. CryptoCompare — historical prices (optional key)

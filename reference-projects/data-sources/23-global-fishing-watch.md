# Global Fishing Watch — fonti dati

- **Portale dati:** [GFW 4Wings AIS API](https://globalfishingwatch.org/our-apis/)

- **Demo:** https://globalfishingwatch.org/map/

Map UI su globalfishingwatch.org; client Python per ingest programmatico.

## API GFW v3 (token gratuito con registrazione) (4)

1. 4Wings API — gridded AIS fishing effort, vessel presence, SAR detections 2017→~5d ago
2. Vessels API — identity, registry, AIS metadata
3. Events API — fishing, encounters, port visits, loitering, gaps
4. Insights API — vessel history analytics

## Dataset sottostanti (4)

1. AIS — vessel positions global
2. Vessel registry — public registries merged
3. SAR — satellite radar detections
4. EEZ / MPA boundaries — marine governance

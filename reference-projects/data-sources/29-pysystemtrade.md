# pysystemtrade — fonti dati

- **Portale dati:** [IB live + Quandl/CSV futures](https://www.interactivebrokers.com/en/trading/ib-api.php)


Focus systematic FX/commodity/index futures. Backtest offline; live richiede IB account.

## Fonti dati futures (5)

1. Interactive Brokers — live futures via ib_async (user account)
2. Quandl / Nasdaq Data Link — historical futures (API key)
3. CSV / Parquet — local price files
4. arctic / legacy — optional tick store
5. Carver futures instrument config — bundled metadata

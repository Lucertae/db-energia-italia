# Herbie — fonti dati

- **Portale dati:** [NOAA NOMADS/NODD GRIB](https://nomads.ncep.noaa.gov/)


Libreria Python per download GRIB/NetCDF. Nessuna API key per NOMADS/NODD pubblici.

1. HRRR — NOAA high-res US (sub-hourly)
2. RAP — NOAA rapid refresh
3. GFS — NOAA global forecast
4. NAM — NOAA North America
5. ECMWF IFS/HRES — open data tier
6. ICON — DWD Germany
7. GEM — Canada
8. NBM — National Blend of Models
9. RRFS — Rapid Refresh Forecast System
